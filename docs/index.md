# PySpace 0.1.0

PySpace is a Python implementation of **S**patial **P**atterning **A**nalysis of
**C**ellular **E**nsembles. Its compatibility target is the public R SPACE
repository at commit `94f0a0f9311e2ee2b406ebc45c84a4e93f2f38f8`.

The package exposes the 24 functions in that revision's R `NAMESPACE` and a
small Python workflow layer. Compatibility is the default: exploratory null
models require an explicit opt-in and report non-parity provenance.

The public tree contains code, documentation, and small synthetic fixtures. It
does not contain clinical data, tissue images, study outputs, manuscripts, or
private research history.

Start with [installation](installation.md), then run the
[table quick start](quickstart.md). For scientific claims and tolerances, read
the [parity methodology](parity.md).
